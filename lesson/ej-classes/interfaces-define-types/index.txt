14:T415,<p>Implementing an interface announces to the world that your class <em>is</em> that type — clients can assign it to the interface and rely on that forever.</p>
<p>A constant interface makes using some constants a permanent part of the public API, even if a later version no longer needs them.</p>
<p>The constants also leak into every subclass&#39;s namespace. Put constants in the class they belong to, an enum, or a <button type="button" class="term" aria-expanded="false" data-term="Noninstantiable class" data-def="A class of only static members, like &lt;code&gt;Math&lt;/code&gt; or &lt;code&gt;Collections&lt;/code&gt;.
